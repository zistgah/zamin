## Ground rules (house conventions)
- **Verify by execution.** Simulate netlists / syntax-check scripts before proposing changes; paste results.
- **Honest figures, flag don't fake.** This is a *design* blueprint — do not present placeholder models or projected numbers as measured silicon.
- **Preserve the poised-zero invariant.** The 0 state is a physical high-impedance ground, never a resistive mid-rail divider.
- **Preserve every file's SPDX + copyright header.**
- **fork → PR → review → merge.** PRs loud (link evidence). Incremental patches only.
- **No irreversible step** (DOI mint, release) without explicit maintainer confirmation; tokens from the environment only.
