This is a research design blueprint, not fabricated or verified silicon. SPICE device
models under spice/models are illustrative placeholders — replace with a foundry PDK
before any simulation used for decisions, and before any tape-out. Report issues via the
GitHub tracker. Never include secrets in reports. Tokens (e.g. ZENODO_TOKEN) are read
only from the environment and must never be pasted into files, issues, or commits.
